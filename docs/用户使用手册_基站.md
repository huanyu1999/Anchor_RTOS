# 铁路施工安全预警装置 — 基站 使用手册

## 1. 产品概述

本设备为铁路施工作业安全预警系统的 **基站（Anchor）** 节点。基站安装于施工防护地点，通过 UWB（超宽带）无线电技术实时测量佩戴标签（Tag）的施工人员距离，当人员进入预设危险区域时，自动触发分级声光报警，提醒人员撤离。

**核心能力：**
- UWB 双向测距（TWR），实时追踪最多 **50 个标签**
- 三级距离报警 + 语音播报
- 双基站 CAN 总线联动，覆盖线路两侧
- 以太网远程监控 + eMMC 日志存储

---

## 2. 外观与接口

### 2.1 指示灯

| 指示灯 | 含义 |
|--------|------|
| **UWB OK** | UWB 模块工作状态指示 |
| **CAN RX** | CAN 总线接收数据时闪烁 |
| **本侧 LED (ONSIDE)** | 亮起表示最近的标签位于**本基站**一侧 |
| **对侧 LED (ACROSS)** | 亮起表示最近的标签位于**对侧基站**一侧 |

> 当无有效标签信号时，本侧/对侧指示灯均熄灭。

### 2.2 按键操作

| 操作 | 动作 | 功能 |
|------|------|------|
| **暂停键** 短按 | 单击 | **静音** — 停止当前语音播报和蜂鸣器 |
| **暂停键** 长按 | 长按 ≥2s | **恢复报警** — 从静音状态恢复为正常报警 |
| **旋钮/开关** 左旋 | 旋至左侧 | 通过 CAN 通知对侧基站**开启报警** |
| **旋钮/开关** 右旋 | 旋至右侧 | 通过 CAN 通知对侧基站**静音** |

### 2.3 DIP 拨码开关（3 位）

基站背面有 3 位 DIP 拨码开关，用于设置**基站编号（Anchor ID）**。

| ID2 | ID1 | ID0 | 基站编号 |
|:---:|:---:|:---:|:--------:|
| OFF | OFF | OFF | 0 |
| OFF | OFF | ON  | 1 |
| OFF | ON  | OFF | 2 |
| OFF | ON  | ON  | 3 |
| ON  | OFF | OFF | 4 |
| ON  | OFF | ON  | 5 |
| ON  | ON  | OFF | 6 |
| ON  | ON  | ON  | 7 |

> **注意：** 拨码开关在**上电时读取**，修改后需重新上电生效。0 号基站为主基站，负责校准标签时序。

## 3. 开机流程

1. **接通电源** — 系统上电，RT9013 稳压器使能，各指示灯短暂全灭。
2. **开机语音** — 约 1.5~2 秒后 JQ8400 语音模块就绪，播放开机提示音。
3. **外设初始化** — 依次初始化 CAN 总线、按键、RTC 时钟、GNSS 模块、DIP 拨码读取。
4. **UWB 启动** — 初始化 UWB 射频芯片（DW1000/DW3000），读取天线延时参数，进入测距状态。
5. **网络就绪** — W5500 以太网模块初始化，建立 TCP 连接。
6. **日志启动** — eMMC 挂载 FatFS，日志写入任务开始运行。

> 整个启动过程约 3~5 秒完成，UWB OK 指示灯亮起后表示已进入测距工作状态。

## 4. 分级报警系统

### 4.1 报警等级

系统根据**最近标签的距离**自动判定报警等级：

| 等级 | 距离范围 | 语音间隔 | 蜂鸣器 | 说明 |
|------|----------|----------|--------|------|
| **安全 (Level 0)** | > 50m 或无标签 | 不播报 | 关闭 | 无报警 |
| **注意 (Level 1)** | 20m ~ 50m | 每 3.6 秒 | 关闭 | 播报标签 ID + 距离 |
| **警告 (Level 2)** | 10m ~ 20m | 每 2.4 秒 | 关闭 | 播报标签 ID + 距离 |
| **危险 (Level 3)** | < 10m | 每 0.8 秒 | **开启** | 仅播报距离（紧急模式） |

### 4.2 语音播报规则

- **10m 以上**：播报格式为 "标签 XX 号，距离 XX 米"
- **10m 以下**（紧急）：只播报距离，不播报标签 ID，缩短反应时间
- **100m 以上**：距离按 5 米精度播报（如 105m 播报为 "105 米"，108m 播报为 "110 米"）
- 语音播报由 JQ8400 模组驱动，通过 BUSY 引脚检测播放状态，避免语音重叠

### 4.3 静音与恢复

- **静音**：短按暂停键，停止语音和蜂鸣器，进入静音状态
- **恢复报警**：
  - 长按暂停键 ≥2s
  - 通过旋钮/CAN 指令恢复
  - **自动恢复**：静音期间如果标签距离**减小超过 3 米**，系统自动恢复报警（防止静音后人员继续接近）

## 5. 双基站联动

系统支持线路两侧各部署一台基站，通过 **CAN 总线**实时交换距离信息。

### 5.1 工作原理

- 每台基站独立完成 UWB 测距，获取本侧最近标签距离
- 通过 CAN 总线实时发送本侧最小距离给对侧基站
- 每台基站综合本侧和对侧距离，取**较近的标签距离**触发报警
- CAN 接收指示灯在接收到对侧数据时闪烁

### 5.2 本侧/对侧判定

- 若本侧距离 < 对侧距离 → 本侧 LED 亮，表示标签更靠近本基站
- 若本侧距离 > 对侧距离 → 对侧 LED 亮，表示标签更靠近对侧基站
- 若对侧基站超过 **2 秒**无数据，视为对侧断联，仅使用本侧距离

### 5.3 远程静音/恢复

通过旋钮操作可跨基站控制报警状态：
- 左旋 → CAN 发送报警恢复指令
- 右旋 → CAN 发送静音指令

## 6. 以太网远程监控

基站配备 W5500 以太网控制器，支持通过 TCP 连接进行远程监控和管理。

### 6.1 网络参数（默认）

| 参数 | 默认值 |
|------|--------|
| IP 地址 | 192.168.1.30 |
| 子网掩码 | 255.255.255.0 |
| 网关 | 192.168.1.1 |
| 上位机 IP | 192.168.1.10 |
| 上位机端口 | 8080 |

### 6.2 通信协议

基站使用自定义二进制 TCP 协议与上位机通信：

| 命令 | 功能 | 方向 |
|------|------|------|
| 0x01 | 查询设备信息（基站 ID、固件版本） | 上位机 → 基站 |
| 0x02 | 查询当前 RF 配置（信道、速率、功率、天线延时） | 上位机 → 基站 |
| 0x03 | 设置 RF 参数 | 上位机 → 基站 |
| 0x10 | 列举日志目录 | 上位机 → 基站 |
| 0x11 | 读取日志文件（分块传输） | 上位机 → 基站 |
| 0x20 | 标签实时状态推送 | 基站 → 上位机 |

### 6.3 标签状态推送

基站每 **500ms** 自动向已连接的上位机推送所有在线标签的状态信息，包括：
- 标签 ID
- 最新测距值（mm）
- 接收信号强度（dBm）
- 距上次测距成功的时间（超过 2 秒视为断联）

## 7. 日志记录

### 7.1 日志存储

日志保存在 eMMC 存储器中，采用 FatFS 文件系统。

**目录结构：**
```
0:/LOG/
  └── YYMM/           （年月目录，如 2606 = 2026年6月）
      ├── 01A00.LOG   （1日，基站 0 号）
      ├── 01A01.LOG   （1日，基站 1 号）
      ├── 02A00.LOG   （2日，基站 0 号）
      └── ...
```

**日志行格式：**
```
[2026-06-22] [14:30:15] [ALM] [T03] 标签3号 距离12.5m 报警Level2
[2026-06-22] [14:30:18] [SYS] 系统开机
[2026-06-22] [14:31:00] [COM] CAN通信故障
```

### 7.2 日志分类

| 类型 | 标识 | 记录内容 |
|------|------|----------|
| 系统 | SYS | 开机、音量变更、UWB 功率、标签响应时长 |
| 报警 | ALM | 语音开启/暂停、报警标签 ID、信号强度、报警来源（本地/CAN） |
| 通信 | COM | CAN 故障/恢复 |

### 7.3 日志导出

日志可通过以下方式导出：

1. **以太网**：上位机通过 TCP 协议发送日志列举（CMD 0x10）和读取（CMD 0x11）命令
2. **USB**（如启用 USB MSC 模块）：基站以 U 盘模式挂载，可直接在电脑上复制日志文件

> USB 挂载期间日志写入自动暂停，卸载后恢复，确保数据一致性。

---

## 8. GNSS 卫星授时

基站内置 GNSS 模块，用于**自动校准 RTC 时钟**，确保日志时间戳准确。

- 授时周期：每 **10 秒**同步一次
- 解析 NMEA RMC 报文，获取 UTC 时间和定位信息（经纬度、速度、航向）
- 定位有效（状态码 'A'）时自动将时间写入 RX8130CE RTC 芯片

## 9. 技术规格

| 项目 | 规格 |
|------|------|
| 处理器 | STM32F405VGTx (Cortex-M4, 168MHz) |
| UWB 芯片 | DW1000 / DW3000（编译选配） |
| UWB 信道 | Channel 5 (DW1000) / Channel 5 或 9 (DW3000) |
| 测距方式 | TWR（Two-Way Ranging，双向测距） |
| 测距精度 | 厘米级 |
| 最大标签数 | 50 |
| 最大基站数 | 2（双基站联动） |
| 报警范围 | 50m（最远预警）~ 10m（危险红线） |
| CAN 总线 | ISO1050 隔离收发器，扩展帧 |
| 以太网 | W5500 (10/100Mbps) |
| 存储 | eMMC + FatFS |
| RTC | RX8130CE，GNSS 自动校时 |
| 语音模块 | JQ8400（UART 控制，BUSY 引脚反馈） |
| 供电 | 外部直流，经 RT9013 稳压 |

## 10. 常见问题

### Q: 开机后没有语音提示？
JQ8400 上电到就绪约需 1.5~2 秒，请确认供电正常。如持续无语音，检查 UART4 连接和语音文件是否已写入 Flash 存储。

### Q: CAN 指示灯不闪烁？
- 检查 CAN 总线接线，ISO1050 隔离 CAN 收发器的 VCC2 **必须接 5V**（Type-C 经二极管压降后可能不足）
- CANH/CANL/VCC2 需相对隔离侧地（GND2）测量
- 确认两台基站的 CAN 波特率一致

### Q: 静音后为什么又自动恢复报警了？
当静音期间检测到最近标签距离**减小超过 3 米**时，系统会自动恢复报警。这是安全保护机制，防止静音后人员继续接近危险区域。

### Q: 如何修改基站编号？
关机后调整背面 3 位 DIP 拨码开关，然后重新上电。0 号基站为主基站。

### Q: 对侧指示灯一直不亮？
表示未收到对侧基站的 CAN 距离数据，检查：
1. 对侧基站是否上电运行
2. CAN 总线是否连通（包括终端电阻）
3. 对侧基站 UWB 是否正常工作

### Q: 以太网无法连接上位机？
检查网线连接，确认上位机 IP 与基站在同一网段（默认 192.168.1.x），上位机需监听 TCP 8080 端口。
